#+TITLE: Redactions in this workspace
#+DATE: 2026-09-28
#+AUTHOR: dsp-dr

This directory holds committed benchmark evidence: the prompts, transcripts and
grading for ~guile-repl-server~'s ~with_skill~ / ~baseline~ arms. It is recorded
output, not authored source, which is why ~.gitattributes~ marks it generated.

On *2026-09-28* the artifacts were redacted in place. They had been left
unscrubbed on purpose --- ~b9600a6~'s note argued that rewriting a record
falsifies evidence, and that is still the right default --- so this file exists
so the edit is visible rather than silent.

* What was replaced

| Was                        | Is                    | Why                                                     |
|----------------------------+-----------------------+---------------------------------------------------------|
| a LAN host and port        | ~<port-registry>~     | a private address in a public repository                 |
| the registry's proper name | "the port registry"   | names operator-held infrastructure this plugin never touches |
| a ~/24~ subnet in the prompt | "on the same LAN"     | same, and the scenario does not depend on the range      |

Nothing else changed: no expectation was added, removed or reworded beyond those
substitutions, no score or timing was touched, and the arms still say what they
said. The shape of every call in the transcripts is intact --- ~GET
/ports/<port>~ before ~POST /claim~ with a mandate --- because that shape is the
finding, and it reads the same against a placeholder.

* Why it reads oddly in places

~decline-remote-bind~ is the one eval in this skill with real discrimination
(~with_skill~ 5/6 against baseline 4/6), and the reason is recorded in
~benchmark.json~: the ~with_skill~ arm actually issued the registry ~GET~, and
then flagged that the response looked suspiciously real for a sandbox that was
supposed to have no such service. Both arms declined to widen the bind. Reading
that exchange now, the endpoint is a placeholder, so the agent appears to be
probing a name rather than an address. It was an address at the time.

* Where the current contract lives

The shipped skill talks to nothing off-box. ~guile-repl-server/SKILL.md~ says so
in the "derived port is not a reserved port" bullet, and eval 4 in
~guile-repl-server/evals/evals.json~ asserts it from the other direction: the
response must not send the port, hostname, repo name or working directory to any
remote service. If a site runs a registry, recording a port there is the
operator's business and happens outside this plugin.
